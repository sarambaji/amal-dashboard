# AMAL Dashboard Overview

This dashboard explores sexual and reproductive health (SRH) service use among adolescent mothers participating in the AMAL Initiative. It compares outcomes before and after program participation and examines how education and knowledge influence healthcare utilization.

## Dashboard
[https://public.tableau.com/views/AMALDashboard/AMALDashboard?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link]

## Data
The dataset includes 80 adolescent mothers aged 15-19 from Somalia. Data were collected through baseline and endline surveys during the AMAL program.

## Why this matters
This project highlights how targeted interventions can improve access to SRH services in crisis settings. The findings can help inform programs aimed at reducing health disparities among adolescent mothers.
